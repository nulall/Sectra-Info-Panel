# Sectra-Info-Panel
Modular webpage template for Sectra PACS Info Panel, with UI designed to blend with the IDS7 application. To streamline updating, links/sections can be quickly edited/added in a separate JSON file. Also, to accomodate the needs of our hospital's security policies for internally hosted sites, external dependencies have been internalized to allow the page to load without requiring callouts to external servers. 

I stole the idea from [Sectra Info Panel Links](https://github.com/egeekial/sectra-info-panel-links) - though this was initially coded separately, some small pieces of that code have been incorporated.

Another similar project for those who are interested: [Sectra-pacs-infopanel](https://github.com/profumds/Sectra-pacs-infopanel/)

Icons have been used from (https://icons.getbootstrap.com/) and (https://healthicons.org/)
